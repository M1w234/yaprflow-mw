# Recording cues

Original synthesized cues created for yaprflow; Apache-2.0, like the project.
No macOS or Windows system-sound recordings are redistributed.

Mono PCM16, 24 kHz. Start: 140 ms, gently rising pitch. Stop: 180 ms, gently falling pitch. Both have smooth attack/release envelopes and peak amplitude 0.35 (-9.1 dBFS) before the app's default 35% gain (combined peak about -18.2 dBFS). System output volume still affects perceived loudness.
