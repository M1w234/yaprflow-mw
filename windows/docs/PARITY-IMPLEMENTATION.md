# Windows parity pass

Scope: streaming text, configurable/imported cues, safe modifier-chord gestures, optional local AI Polish, opt-in correction learning, live microphone discovery, and interface refinement. Public publication remains separate.

Surface: Windows companion. Mode: Operate. Intent: act on settings; scan recent dictations.
Data: five small settings groups; up to 200 history items; up to 500 vocabulary entries.
Form: left navigation with flat settings sections; history/vocabulary retain list/detail views.
Grouping: Dictation, Shortcuts, Sound, Privacy, Models; History and Vocabulary alongside.
Filtering: live local history search, in-place search box; newest first.
Editing: immediate reversible preferences; Apply for hotkeys because registration can fail.
Nesting: one window; native file picker only for audio/model files. No nested settings dialogs.
Density: 36-DIP controls, 8/16/24 spacing, 14-DIP body, 24-DIP heading.
Style: refined utilitarian native Windows; deliberate Segoe UI exception for accessibility and familiarity. Light sage canvas #F3F6F3, warm surface #FCFDFB, ink #20332D, muted #53675E, accent #246B53; high-contrast uses OS colors. Two weights; flat surfaces; no decorative gradients or shadows.
States: first download, ready/offline, listening/live draft, finalizing, canceled, unavailable microphone, unavailable Polish model, insertion withheld, empty history, no search results.
Rejected: a single long Settings form makes infrequent model/privacy choices obscure daily audio/shortcut choices. Nested cards add clutter.

Verification gates: cancellation/race tests for streaming; key-chord false-trigger tests; privacy/field checks for learning; corrupt file/model handling; settings migration; native Windows screenshots; real microphone and runtime checks; signed release later.
